# Windy20000 Tap

## How do I install these formulae?

`brew install windy20000/tap/<formula>`

Or `brew tap windy20000/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "windy20000/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
